# Fund × Data 净值基准比较

本地开发，2026-10-25；尚未生产部署。

基金详情 → 概览 → 净值支持多选标普 500、BTC/USDT、上证指数和纳斯达克 100。未选基准时显示原始单位净值；选择后显示起点归一为 1 的走势，可切累计收益百分比。基金真实记录日显示圆点，连续时间轴体现记录间隔，不填造每日净值。总资产、份额及账本计算仍沿用原有接口。

默认采用各自原币收益，BTC 使用既有 BTCUSDT。可切换基金币种，USD/CNY 通过现有 Data 历史参考汇率换算；不把 USDT 等同 USD，BTC 无换算数据时明确显示不可用。指数口径为价格收益，不含股息再投资。

## 后端契约

- `GET /api/v1/benchmarks`：受保护的四项目录。
- `GET /api/v1/funds/{id}/benchmark-comparison?ids=sp500,btc,sse_composite,nasdaq100&currency_mode=native`：可带 `start_date`、`end_date`；币种模式为 `native` 或 `fund`。
- viewer 可读，复用 Fund 会话；浏览器不获取 Data API Key，不要求第二次登录 Data。Data 深链接仅用于查看原始标的。
- Data 的 URL、Key 和 timeout 复用现有 `DATA_TERMINAL_*` 配置；新增 `BENCHMARK_CACHE_PATH` 默认 `./data/benchmark-cache.json`。前端 `VITE_DATA_TERMINAL_URL` 默认生产 `/data` 完整站点地址，隔离测试可覆盖。

Data 返回完整已确认日线及预期交易日期，Fund 统一进行日期、币种、归一化与指标计算。基金净值每次读最新账本，不缓存计算结果。最多四项、20 年，非法参数明确报错。

共同有效起止必须是所有可用曲线都具备有效参考价的真实基金记录日。休市沿用上一交易日，显示 `source_date`；应交易但缺价格时断线，不反向填充。少于两个基金点或没有共同区间时提示并保留原始净值。缺口曲线不计算区间收益和收益差。不可用基准始终保留原因。基金收益差是百分点，不称风险调整 alpha。

当前 policy 为 `market-date-native-default-v1`：按市场日期匹配，非同一瞬间估值，也不是历史可得性回测。Fund 缺少统一估值 cutoff，不能假装知道真实盘中时点。历史汇率按目标日期向前取值，超过七个自然日不可用于本次比较；不套用当前汇率覆盖整段历史。

## 缓存与故障

批量历史缓存五分钟、最多 32 个区间，持久化文件权限 600，缓存按数据源和凭据哈希隔离。重启重新核验。临时故障可用同区间上次成功行情，页面显示缓存警告和原核验时间；没有缓存则提示并保留原始净值。401/403 清理缓存，不能在权限明确失效后继续展示。拒绝重定向，Key 不发送到其他目标；凭据不写入缓存或前端。

个人选择保存在 URL 和当前用户/基金的 localStorage，切换请求会取消过期结果，不新增基金级持久配置或写权限。数据表、真实报价/汇率日期浮窗和手机局部横向滚动可供核对。
